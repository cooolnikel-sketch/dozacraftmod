# DozaCraft — сайт загрузки мода

Минималистичный статический сайт для GitHub Pages. Нет разделов FAQ, каталога функций или ненужных описаний: главный экран, скриншот из игры, версии мода/Minecraft и установка.

## Настройка

В `config.js` замени `YOUR-USERNAME` на свой GitHub-ник и проверь имя JAR-файла. Чтобы кнопка скачивала последний файл напрямую, ссылка обычно имеет вид:

`https://github.com/USERNAME/REPOSITORY/releases/latest/download/имя-файла.jar`

Для каждой версии добавь строку в `versions` в формате `{ mod: '1.2.4', minecraft: '26.3', loader: 'Fabric', url: 'https://...jar' }`.

## Панель управления

Нажми ⚙ в шапке сайта. Там можно изменить ссылку на скачивание, репозиторий и список версий. Изменения панели сохраняются **только в текущем браузере**. Это ограничение GitHub Pages: браузер не может безопасно перезаписать публичные файлы сайта.

Для постоянной публикации скопируй сформированный панелью объект конфигурации в `config.js`, закоммить и отправь изменения в GitHub. Не вставляй в HTML или JavaScript приватные GitHub-токены.

## Публикация на GitHub Pages

1. Загрузи содержимое этой папки в корень репозитория сайта.
2. Открой **Settings → Pages**.
3. Выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми **Save**.
4. Настрой ссылки в `config.js`.

## Файлы

- `index.html` — страница.
- `style.css` — оформление.
- `script.js` — список версий и панель настроек.
- `config.js` — публичные настройки и ссылки.
- `assets/dozacraft-gameplay.png` — предоставленный скриншот Minecraft.
