INSTALLATION

Установка

  1. Установи Fabric Loader для нужной версии Minecraft.
  2. Скачай JAR-файл подходящей версии.
  3. Перемести файл в папку .minecraft/mods.
  4. Запусти игру с профилем Fabric.
