02 / НАЧАЛО РАБОТЫ

Установить.
Подключиться. Готово.

WebcamBubbles должен быть установлен на сервере и на каждом клиенте, который хочет отправлять или видеть камеры.

01

Подготовь Fabric

Установи Minecraft Java 26.3, Java 25+, Fabric Loader и совместимую версию Fabric API.

ОБЯЗАТЕЛЬНО
02

Добавь мод в обе стороны

Помести webcambubbles-1.2.4.jar в папку mods/ на сервере и на клиентах. Перезапусти игру и сервер.

СЕРВЕР + КЛИЕНТ
03

Запусти камеру

Нажми V, чтобы включить или выключить трансляцию. Нажми G, чтобы открыть настройки камеры.

ГОТОВО
04

Проверь сеть

Без Simple Voice Chat настрой UDP-порт из конфига (по умолчанию 25566). С Simple Voice Chat мод пытается использовать его UDP-сокет автоматически.

04 / FAQ

Коротко о главном.

Ответы на вопросы, которые возникают при первой установке.

Нужно ли ставить мод на сервер? +

Да. Установи WebcamBubbles на сервер и на каждый клиент, который должен отправлять или отображать веб-камеры.

Обязателен ли Simple Voice Chat? +

Нет, это необязательная интеграция. Если SVC установлен и его сокет доступен, мод пытается использовать общий UDP-транспорт. Иначе используется отдельный UDP-порт.

Почему не видно камеру другого игрока? +

Проверь, что обе стороны используют совместимые версии мода, игрок включил трансляцию, а сетевой UDP-транспорт доступен. Если SVC не установлен, проверь порт из конфига и правила файрвола.

Куда загружать новые версии мода? +

В GitHub-репозитории открой Releases → Draft a new release, создай тег версии и прикрепи собранный JAR. Сайт ведёт на страницу последнего релиза. Сам GitHub Pages не принимает файлы в репозиторий через обычную форму сайта.

Безопасно ли использовать мод на публичном сервере? +

Мод задуман для приватных серверов, где участники знают о трансляции и согласны с ней. Не используй веб-камеры для скрытой записи или без согласия игроков.

Где лежат настройки? +

После первого запуска открой config/webcambubbles.json. Большинство настроек камеры также доступны через клавишу G.
